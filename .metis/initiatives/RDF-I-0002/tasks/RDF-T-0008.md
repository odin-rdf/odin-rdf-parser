# N-Quads parser

## Parent Initiative

[[RDF-I-0002]]

## Objective

Implement the N-Quads parser in package `rdf/quads`: the same API and semantics as `rdf/triples`, extended with the optional graph label, yielding borrowed `rdf.Quad` statements.

## Acceptance Criteria

## Acceptance Criteria

- [x] Same API shape as `rdf/triples` with `parser_next(p) -> (rdf.Quad, bool)`; identical error and lifetime contracts.
- [x] Conforms to the W3C RDF 1.2 N-Quads grammar: optional graph label (IRI or blank node) before the terminating dot; absent label yields a `nil` `Graph_Label` (default graph).
- [x] Statement parsing is shared with `rdf/triples` through the internal package — the graph-label extension is the only quads-specific grammar code, no copy-pasted term parsing.
- [x] Zero allocation for escape-free statements, including ones with graph labels (tracking-allocator test).
- [x] Unit tests: quads with IRI graph labels, blank-node graph labels, and no label; malformed graph-label cases (e.g., a literal as label) with expected error kinds and positions; `odin check -vet -strict-style` clean.

## Implementation Notes

### Technical Approach
By this point the shared statement core exists (factored in RDF-T-0007); this task is the thin quads layer plus its test matrix. If the factoring turns out wrong for the graph-label extension, fix it here rather than duplicating.

### Dependencies
RDF-T-0007 (shared statement-parsing core is factored during the N-Triples parser).

## Status Updates

**2026-08-04**: The factoring from RDF-T-0007 held: the only new grammar code is `parse_optional_graph_label` in `rdf/internal/statement` (peek: a directly following Dot means default graph → `nil`; IRI/blank node consume as label; anything else is `Invalid_Graph_Label`). `rdf/quads` itself is a thin composition — subject → predicate → object → optional graph label → dot — with the same `using`-embedded core, sticky errors, and lifetime contract as `rdf/triples`.

Tests: 5/5 (all three graph-label cases, triple term inside a quad with a named graph, zero-allocation escape-free guard including labels, escaped-graph-label CoW freed on destroy, 5 negative cases incl. literal-as-label and sticky errors). Full suite across all packages: 36/36; `-vet -strict-style` clean. Task complete.
