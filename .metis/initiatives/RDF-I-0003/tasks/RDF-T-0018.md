# Turtle and TriG emitters with round-trip tests

## Parent Initiative

[[RDF-I-0003]]

## Objective

Implement Turtle and TriG emitters per the approved scope: spec-valid output with minimal prefix-aware abbreviation — caller-supplied prefix map, `a` keyword, and `;`/`,` grouping via one-statement lookbehind — validated by round-trip tests (parse → emit → parse yields the same statements).

## Acceptance Criteria

## Acceptance Criteria

- [ ] Emits every term type: IRIs (abbreviated to a prefixed name on longest-prefix match only when the remainder is a valid `PN_LOCAL`, with reserved-character escaping; full `<>` form otherwise), blank nodes, all literal forms (lexical value preserved as parsed, escaping via `rdf/internal/emit`), and the RDF 1.2 constructs (triple terms; reified/annotation forms may emit as their expanded triples — decide and document).
- [ ] `rdf:type` in predicate position emits as `a`; consecutive statements with the same subject group with `;`, same subject+predicate with `,` — one-statement lookbehind only, no reordering or buffering.
- [ ] A `@prefix` header is emitted for exactly the prefixes actually used (or all supplied — decide and document); an empty prefix map yields flat, full-IRI output.
- [ ] TriG emitter wraps in graph blocks with the same grouping inside a block; default graph emits unwrapped.
- [ ] Round-trip property tests: for corpora covering every construct, parse → emit → parse produces identical statement sequences (modulo synthesized labels); emitted output for the numeric/boolean/string abbreviation cases re-parses to the same lexical forms and datatypes.
- [ ] Emitter allocation discipline matches the N-Triples/N-Quads emitters, guard-tested.

## Implementation Notes

### Technical Approach

Same emitter architecture as `rdf/internal/emit` consumers: streaming writer, per-statement state limited to the previous statement's subject/predicate for grouping decisions. Prefix matching via longest-match over the supplied map (sorted or trie if profiling demands; linear scan over a handful of prefixes is fine to start).

### Dependencies

`rdf/internal/emit` escaping core. Round-trip tests need the parsers: Turtle side after [[RDF-T-0015]] (structures), full coverage after [[RDF-T-0016]]/[[RDF-T-0017]]. Can start once [[RDF-T-0015]] lands.

### Risk Considerations

Abbreviation correctness is subtle: a prefixed name must re-parse to the identical IRI, so `PN_LOCAL` validity checking (including dot rules and escape requirements) must be exact — reuse the scanner's classification from [[RDF-T-0012]] rather than reimplementing it. The round-trip property is the safety net; run it over the vendored W3C positive corpora in [[RDF-T-0019]] once available.

## Status Updates

**2026-08-04 — Completed.** Emitter core in `rdf/internal/ttl/emitter.odin`, public wrappers `rdf/turtle/emitter.odin` + `rdf/trig/emitter.odin`; 36 turtle + 10 trig tests pass, full suite green.

Decisions the ACs left open, now made and documented in code:
- **`@prefix` header**: all supplied bindings, used or not — deterministic and streaming-friendly (usage isn't known upfront).
- **RDF 1.2 output forms**: triple terms emit as `<<( … )>>`; reification/annotation emit as their expanded triples (`rdf:reifies` + triple term) — the parser expanded them, and re-abbreviating would need lookahead the scope excludes.
- **PN_LOCAL escaping policy**: interior dots raw, edge dots escaped; `%` raw only before a valid hex pair, else `\%`; the other `PN_LOCAL_ESC` characters always escaped (`_`/`-` are `PN_CHARS`, raw). Abbreviation happens only when `local_emittable` proves the local re-parses to the identical IRI; otherwise full `<>` via the shared `em.write_iri` (made public along with `write_escaped`).
- **Lookbehind lifetime**: prev subject/predicate/graph are copied into emitter-owned capacity-reusing buffers, so triples can stream directly from a parser whose terms die per statement. Guard test proves steady-state emission allocates nothing.
- **TriG blocks**: graph changes close and reopen blocks (no merging across interleavings — streaming); default graph unwrapped; grouping works inside blocks with deeper continuation indent.
- Round-trip tests compare with a **blank-node bijection** (fwd+bwd maps) because the parser's `^B*b[0-9]+$` remapping makes exact labels unstable across a round trip by design — this comparator is the seed for the [[RDF-T-0019]] eval harness. Both prefixed and flat round trips pass over a corpus covering every construct; running it over the vendored W3C corpora happens in T19.
