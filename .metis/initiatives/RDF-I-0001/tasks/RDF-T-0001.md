# Package skeleton and core term types

## Parent Initiative

[[RDF-I-0001]]

## Objective

Create the library's package skeleton and implement the core term types in the root `rdf` package, exactly as shaped by ADR RDF-A-0002.

## Acceptance Criteria

## Acceptance Criteria

- [x] Repository layout matches the resolved package design: core `rdf` package at the root; format packages (`triples`, `quads`, `turtle`, `trig`) arrive in later initiatives, not here.
- [x] `IRI` and `Blank_Node` defined as `distinct string`, with doc comments stating that blank node labels are stored without the `_:` prefix.
- [x] `Direction` enum (`None`, `LTR`, `RTL`) and `Literal` struct (lexical, datatype, language, direction) defined, with the langString/dirLangString invariants stated in doc comments.
- [x] `Term` union over `IRI`, `Blank_Node`, `Literal`, `^Triple` and the `Triple` struct defined; `odin check` passes.
- [x] Type definitions and zero-value construction perform no allocation.

## Implementation Notes

### Technical Approach
Follow the sketch in ADR RDF-A-0002 verbatim; the naming and field order fixed here become the reference for all later work. Constructors, quads, and vocabulary constants land in RDF-T-0002.

### Dependencies
None — first task of the initiative.

## Status Updates
