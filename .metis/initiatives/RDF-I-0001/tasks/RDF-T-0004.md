# Equality and hashing proc groups

## Parent Initiative

[[RDF-I-0001]]

## Objective

Implement structural equality and hashing as overloaded proc groups (`rdf.equal`, `rdf.hash`) over directly-callable per-type procedures, with the semantics fixed by ADR RDF-A-0002.

## Acceptance Criteria

- [ ] Per-type procedures for `Term`, `Triple`, `Quad` (and `Graph_Label`), collected into `equal` and `hash` proc groups.
- [ ] Equality is structural and buffer-independent: identical content borrowed from different buffers compares equal; verified by a test using two separate buffers.
- [ ] Equality and hashing recurse through nested triple terms; `Graph_Label` participates in quad equality with `nil` (default graph) handled correctly.
- [ ] Hashing uses FNV-1a from `core:hash`, isolated behind one internal procedure so the function can be swapped without any public API change.
- [ ] Property exercised in tests: `equal(a, b)` implies `hash(a) == hash(b)`, including literal corner cases (same lexical, different datatype/language/direction must differ).

## Implementation Notes

### Technical Approach
Hash the variant tag plus each component's bytes; for literals include datatype, language, and direction so the RDF 1.2 distinctions are honored. No allocation anywhere in equality or hashing.

### Dependencies
RDF-T-0002 (complete type set). Independent of RDF-T-0003 — can proceed in parallel.
