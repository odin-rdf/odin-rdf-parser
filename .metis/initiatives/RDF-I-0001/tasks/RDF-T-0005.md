## Objective

Close out the initiative with a comprehensive unit-test suite and documentation of the public API, satisfying the initiative's testing and documentation goals.

## Acceptance Criteria

- [ ] `core:testing` tests cover construction (including via constructors) for every term kind, with nested triple terms exercised at least two levels deep.
- [ ] Equality/hashing tests: positive and negative cases per kind, buffer-independence, and the `equal ⇒ same hash` property (may consolidate tests written in RDF-T-0004).
- [ ] Memory tests: tracking allocator confirms clone/destroy and the intern table are leak-free across all term kinds.
- [ ] Every public declaration carries a doc comment; a package-level doc states the borrow/clone lifetime contract from RDF-A-0001 prominently.
- [ ] `odin test` is green; the initiative's exit criteria are reviewable against this suite.
