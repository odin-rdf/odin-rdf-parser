# Top-level README with quick-start and package guide

## Objective

Give the repository a top-level `README.md` that serves as the entry point for Odin developers and downstream projects — the first real consumer being the upcoming `odin-rdf-sparql`. A reader should understand within minutes what the library is, what it guarantees, and how to parse and emit each format.

## Backlog Item Details

### Type
- [x] Tech Debt - Code improvement or refactoring

### Priority
- [x] P1 - High (important for user experience)

### Technical Debt Impact
- **Current Problems**: The only markdown in the repo is `tests/w3c/README.md`. There is no entry point explaining what the library does, which package to import, or how the parser/emitter APIs are used. The vision's "public API is documented" success criterion (RDF-V-0001) is unmet at the repo level.
- **Benefits of Fixing**: `odin-rdf-sparql` (and any other consumer) can onboard from the README instead of reverse-engineering tests; conformance and performance results become visible instead of buried in Metis notes.
- **Risk Assessment**: Without it, downstream developers rediscover contracts by reading source, and the library's 100% W3C conformance story goes unadvertised.

## Acceptance Criteria

## Acceptance Criteria

- [x] `README.md` at the repo root states what the library is, its scope (four formats + core data model, RDF 1.2 including RDF-star), and its non-goals (stores, SPARQL, SHACL are downstream projects).
- [x] Package map with one-line descriptions: `rdf` (core model), `rdf/triples`, `rdf/quads`, `rdf/turtle`, `rdf/trig`.
- [x] Quick-start examples: parse Turtle into triples (`parser_init` / `parser_next` loop / `parser_destroy`) and emit triples as Turtle. Example code must actually compile — mirror it in a small test or extract from existing tests.
- [x] Memory-model summary: caller-owned `[]byte` input, borrowed slices, per-statement validity, clone/intern to retain terms — brief, with a pointer to the package API docs ([[RDF-T-0023]]).
- [x] Conformance statement: all 1045 tests across the 10 vendored W3C suites pass; throughput baselines quoted from `bench/`.
- [x] Build and test instructions (`odin test`, how to run benchmarks).

## Implementation Notes

Source material already exists: initiative status updates (RDF-I-0002/0003), ADRs RDF-A-0001/0002, and the test files for compiling example code. Keep the README factual and short; deep contract detail belongs in package docs ([[RDF-T-0023]]), not here.

### Dependencies
None hard. Ideally lands after or alongside [[RDF-T-0023]] so links point at real doc comments.
